verify the SHA-256 identities stored in the source manifests. A project-level
license does not replace the licenses below.

Install the external source files with `python scripts/setup_third_party.py`.
These directories are ignored by Git. The script downloads only the pinned,
hash-verified files needed by the adapters; it does not grant any additional
rights to upstream code. Consult the upstream projects for their distribution terms.

CodeRAG includes only its pinned query-construction reference and MIT license.
Other included snapshots retain their upstream notices and hashes.

`utils/build/` retains the existing Linux Python parser library used by the
evaluation code. Their file hashes and format are recorded in
`utils/build/PARSER_LIBRARIES.json`; the original build revision was not recorded
in the source workspace.

Datasets, repository snapshots, model weights and tokenizers are obtained
separately under their own terms. See README.md for runtime setup.

The attribution headers in `utils/eval_utils.py` (Amazon, Apache-2.0),
`utils/keywords/keywordlist.py` (Microsoft, MIT)
are retained. Their license texts are included under `LICENSES/`.
